A few things to know.

Does DONE control my appliances?

You start and operate the appliance yourself. DONE tracks the timer and the completion you confirm, with no additional hardware.

What if I do not know the duration?

Start the stopwatch and stop it when the appliance finishes. Name the program and save the measured duration for next time.

Can I share a session?

Yes. Send a viewing link from the app. It opens in a browser, updates every five minutes and can be revoked from DONE.
